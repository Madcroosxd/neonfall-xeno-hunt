# NEONFALL V12 — Combat & Polish Update

## Fixed

- Removed invisible, unavoidable ranged damage.
- UFO and boss ranged attacks now use visible telegraphs and dodgeable projectiles.
- Added a short damage grace period so overlapping enemies cannot erase HP every frame.

## Combat

- Added an invulnerable phase dash on `SPACE` with a visible cooldown meter.
- Added distinct enemy projectile patterns: aimed bolt, cone wave, and radial boss burst.
- Added hit flashes and enemy death shards for clearer combat feedback.
- Added automatic repair between completed waves.

## Progression

- Added maximum-health, damage-reduction, dash-recharge, and wave-repair upgrades.
- Existing attack, critical, fire-rate, projectile, movement, lifesteal, magnet, and luck builds remain available.

## Presentation

- Replaced the flat arena with the authored space-arena background.
- Activated the existing marine run animation and alien/boss atlas artwork.
- Expanded the HUD with dash charge, threat count, controls, wave banners, and health-state feedback.
